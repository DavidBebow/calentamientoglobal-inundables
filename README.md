# calentamientoglobal-inundables

Datos estáticos de zonas inundables por periodo de retorno para calentamientoglobal.es (Pages desde `docs/`).

- Fuente: © Ministerio para la Transición Ecológica y el Reto Demográfico, Sistema Nacional de Cartografía de Zonas Inundables (SNCZI). Uso libre citando la fuente.
- `docs/index.json`: índice, cifras nacionales, por demarcación y provincia, clasificaciones.
- `docs/prov/t<T>/<provincia>.json`: vista general. `docs/mun/t<T>/<INE>.json`: detalle. `docs/mun/<INE>.json`: cifras y frase del municipio.
- Método y límites: `docs/LEEME.md`.
